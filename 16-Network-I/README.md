# Network Fundamentals & Linux System Basics

This module covers essential networking concepts, numbering systems, and low-level Linux administration tools.

## 1. Numbering Systems with `bc`
*   **Objective:** Practice converting decimal values to Binary and Hexadecimal formats using the `bc` utility.
*   **Key Learning:** Mastering `ibase` and `obase` parameters to understand how computers process IP and MAC addresses.

## 2. Linux Permissions & Octal Notation
*   **Objective:** Create a "Dark Directory" by applying specific octal permissions using `chmod`.
*   **Key Learning:** Understanding the bitwise structure (4-2-1) of Linux permissions, specifically the difference between directory "read" (list) and "execute" (enter) rights.

## 3. ARP Protocol & Network Discovery
*   **Objective:** Identify the MAC address of the default gateway using `ip route` and the `arp` utility.
*   **Key Learning:** Mapping logical IP addresses to physical hardware addresses
